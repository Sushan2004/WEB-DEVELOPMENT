## About

This project demonstrates how to create a simple mobile-style interface using HTML/CSS for the front-end and Java (JavaFX) for the backend logic. It's perfect for beginners learning Java and GUI concepts.

---

## Features

* Mobile-style window using JavaFX WebView.
* Basic HTML/CSS interface.
* Interactive button that shows a message.

---

## Installation

1. **Clone the repository**

```bash
git clone https://github.com/your-username/java-mobile-interface.git
```

2. **Navigate to the project folder**

```bash
cd java-mobile-interface
```

3. **Compile Java files**

```bash
javac -cp path/to/javafx/lib/* src/Main.java
```

4. **Run the program**

```bash
java -cp .;path/to/javafx/lib/* Main
```

> Replace `path/to/javafx/lib/*` with the location of your JavaFX SDK libraries.
